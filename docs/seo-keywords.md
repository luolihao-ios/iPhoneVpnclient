# Forge VPN SEO 关键词与项目简介

Forge VPN is a cross-platform VPN client for Windows, Android and iOS, built with Flutter and integrated with sing-box. It provides a desktop-friendly sing-box GUI, subscription import, node health checks, global proxy and smart routing.

## 项目范围

Forge VPN 是客户端软件，不提供 VPN 订阅、服务器、账号或代理线路。用户需要自行导入可信的订阅地址。项目支持 Windows 安装包、Android APK 和 iOS 测试包，具体下载入口位于 [README](../README.md) 和 [GitHub Releases](https://github.com/luolihao-ios/iPhoneVpnclient/releases)。
