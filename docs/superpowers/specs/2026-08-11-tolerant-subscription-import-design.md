# 容错订阅导入设计

## 目标

让 Forge VPN 能稳定导入 `0xRadikal/Free-v2ray-Configs` 发布的四类订阅：纯文本 URI、Base64 URI、Clash YAML 和 sing-box JSON。单个节点的非标准名称或损坏内容不得导致整份订阅失败。

## 范围

- 保留 VMess、VLESS、Trojan、Shadowsocks、AnyTLS 和 WireGuard 的现有支持。
- Shadowsocks URI 的 `#` 后名称允许直接包含空格、国旗、中文等 Unicode 字符。
- 名称包含合法百分号编码时正常解码；编码损坏时保留原文。
- 逐行 URI 订阅采用故障隔离：单个节点解析异常时跳过该节点，继续解析其余节点。
- 仅当最终没有任何受支持节点时，整份订阅才返回失败。
- Base64 订阅解码后复用同一套逐行容错逻辑。
- Clash YAML 和 sing-box JSON 继续使用各自的结构化解析器。
- 诊断日志只记录成功数与跳过数，不输出节点密码、UUID、私钥或完整订阅正文。

## 非目标

- 本轮不改变节点健康检查、30 秒批次限制、自动筛选数量或界面展示数量。
- 本轮不新增 SSR 支持；当前 sing-box 核心不支持 SSR。
- 本轮不承诺免费节点在用户当前网络中一定可连接。

## 数据流

1. 下载订阅正文。
2. 优先识别 JSON 或 Clash YAML；识别成功后使用结构化解析器。
3. 对 URI 文本或 Base64 解码后的 URI 文本逐行解析。
4. 每行解析异常只增加跳过计数，不终止循环。
5. 去重并过滤元数据节点。
6. 有节点则返回；无节点则报告订阅格式或节点不可用错误。

## 测试

- 未编码 Unicode Shadowsocks 名称能够原样保留。
- 合法百分号编码名称能够解码。
- 损坏百分号编码名称不会中断导入。
- 一个损坏节点与一个有效节点共存时仍返回有效节点。
- Base64 包装的同类订阅行为一致。
- 代表性的 Clash YAML 与 sing-box JSON 仍能解析。
- 现有订阅解析测试全部保持通过。
