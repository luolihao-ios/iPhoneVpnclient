# Windows 浅色桌面界面设计

## 目标

将 Windows 界面统一为白底、深色文字和清晰边框的桌面软件风格，参考用户提供的蓝色顶部导航与浅蓝侧栏布局，降低大面积深色块和厚重阴影带来的压迫感。

## 视觉规范

- 顶部栏：蓝色渐变背景，品牌名称与主要操作使用白色。
- 侧栏：浅蓝灰背景，当前菜单使用蓝色胶囊或浅蓝高亮。
- 内容区：白色背景，主文字使用深蓝黑色，辅助文字使用中灰色。
- 卡片：白底、1px 灰蓝边框、适度圆角，不使用深色填充。
- 表格：浅灰蓝表头、白色行、细分隔线；分组标题使用浅蓝底色。
- 状态色：绿色只表示已连接/可用，红色表示错误，蓝色表示普通操作。
- 保持移动端的信息结构和中文文案，但 Windows 使用顶部导航、左侧导航和更宽的表格布局。

## 改造范围

- `lib/main.dart`：Material 主题、顶部导航和桌面导航栏。
- `lib/widgets/responsive.dart`：统一颜色、边框和间距令牌。
- `lib/screens/dashboard_screen.dart`：节点卡片、统计卡片、订阅节点表格。
- `lib/screens/settings_screen.dart`、`lib/screens/logs_screen.dart`、`lib/screens/nodes_screen.dart`：统一白底、文字和控件状态。
- `lib/widgets/subscription_import_card.dart`：输入卡片和导入按钮。

## 行为约束

不改变代理、订阅、节点检查、托盘和核心进程逻辑，只调整布局和视觉表现。保留现有响应式规则：手机继续使用底部导航，Windows 使用侧栏和顶部栏。

## 验收标准

1. Windows 主界面不出现大面积黑色背景或黑色表头。
2. 所有主要文字在白底上有足够对比度，边框清晰可见。
3. 已连接、错误、检查中和可用状态仍能通过颜色和中文标签区分。
4. 现有节点、代理和订阅相关测试保持通过。
