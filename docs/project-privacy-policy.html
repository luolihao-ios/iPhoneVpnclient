Forge 隐私政策

生效日期：2026 年 8 月 13 日

Forge 是一款跨平台网络代理客户端，支持 Windows、Android 和 iOS。Forge 本身不提供、销售或运营 VPN 节点、订阅服务或互联网接入服务。用户需要自行取得并配置合法可用的订阅地址或节点信息。

一、我们处理的信息

Forge 无需注册账号即可使用。应用可能在设备本地处理用户主动填写的订阅地址、节点配置和认证凭据，以及所选节点、路由模式、DNS 解析器、界面语言、连接状态、诊断结果和运行日志。上述内容默认保存在用户设备本地，Forge 开发者不设置自有服务器接收这些内容，也不将其用于广告画像。

二、网络连接与第三方服务

用户启用连接后，网络流量会按照用户选择的模式交由用户自行配置的代理节点、订阅服务商、DNS 解析服务商和目标网站处理。这些第三方可能依据其自身隐私政策处理网络请求。为了完成订阅导入、DNS 解析、节点连通性检测和版本检查，应用可能访问用户填写的订阅地址、公共 DNS 服务、公共 HTTP 204 检测地址及 GitHub Releases。

三、系统权限

Android 和 iOS 版本会申请系统 VPN/Network Extension 权限，以创建本地虚拟网络接口并转发网络流量。Windows 版本可能修改系统代理设置。这些权限仅用于用户主动开启的连接功能。Forge 不会在未经用户操作的情况下读取通讯录、照片、短信、通话记录、精确位置、麦克风或摄像头。

四、日志与导出

运行日志默认仅保存在设备本地。用户主动导出日志时，文件将由用户选择的系统分享方式或保存位置处理。日志可能包含节点域名、目标域名、连接状态和错误信息，分享前请自行检查。

五、数据共享、出售与广告

Forge 不出售用户个人信息，不向广告平台提供用户数据，也不集成用于跨应用追踪的广告 SDK。除用户主动配置的第三方网络服务、系统功能或法律法规要求外，Forge 开发者不会主动向第三方传输用户的本地配置和日志。

六、数据保留与删除

本地配置、缓存和日志会保留在用户设备上，直至用户在应用内清除数据、卸载应用或通过操作系统删除应用数据。第三方服务保留的数据由相应服务商负责。

七、儿童隐私

Forge 不以儿童为目标用户，也不会主动收集儿童个人信息。未成年人应在监护人指导下使用。

八、安全与责任范围

Forge 采取合理措施减少本地敏感信息暴露，但网络传输和设备存储无法保证绝对安全。用户应妥善保管订阅地址和节点凭据，并仅使用可信服务商。

九、政策更新

当应用功能、权限或数据处理方式发生变化时，本政策可能更新。更新后的政策将在本页面发布，并修改生效日期。
